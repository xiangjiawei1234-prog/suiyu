# 岁予 · Suiyu

> 把每个生日，过成值得记住的一天。

一款**完全在本地运行**的生日计算器：公历与农历生日换算、双生日重逢日历、亲友生日清单，全部装在一个 HTML 文件里，双击即用、离线可用。

**[在线使用](https://xiangjiawei1234-prog.github.io/suiyu/)** · [功能](#功能) · [说明与边界](#说明与边界) · [使用方式](#使用方式)

![岁予界面预览](preview.png)

## 功能

- **生日小档案** —— 输入公历出生日期，得到农历生日、生肖、星座、周岁、来到世界的天数，以及下一次公历 / 农历生日倒计时。
- **双生日重逢日历** —— 查看未来 50 / 100 / 150 / 200 年里，每年公历生日与农历生日对应的日期，按相差天数筛选（只看重合、3 天内、10 天内、30 天内），可按年份或相差天数排序。
- **在乎的人** —— 保存亲友生日，按「下一个生日」远近排序，临近的人一眼可见；点开卡片即可重新查看，删除后支持撤销。
- **导出到系统日历** —— 为单人或全部亲友生成 `.ics` 文件，包含未来的公历生日、农历生日与双生日重合事件，导入系统日历即可提醒。
- **导出表格** —— 双生日对照表可导出为 CSV（带 UTF-8 BOM，Excel 直接打开不乱码）。
- **一键复制** —— 把生日小档案复制成纯文本，随手发给朋友。

## 说明与边界

- 农历数据覆盖 **1900—2100** 年，超出范围会明确提示。
- 2 月 29 日生日在非闰年按 2 月 28 日处理；农历闰月、月末缺失会就近处理，并在结果中标注。
- 所有换算和数据存储都在浏览器本地完成，**不上传任何个人信息**；保存的生日存放在当前浏览器的 `localStorage`，不会跨设备同步。
- 清除浏览器数据前，建议先导出 `.ics` 或 CSV 备份。
- 单文件、零依赖、无外部请求，断网也能正常使用。

## 使用方式

**在线使用**：<https://xiangjiawei1234-prog.github.io/suiyu/>

**离线使用**：下载或克隆本仓库，双击 `index.html` 即可。也可以起一个本地静态服务：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤、无第三方依赖。
- 农历换算基于 1900—2100 年的农历数据表，实现公历与农历双向转换。
- `.ics` 按 iCalendar 格式生成；CSV 导出带 UTF-8 BOM。
- 响应式布局，桌面与手机浏览器均可使用。
